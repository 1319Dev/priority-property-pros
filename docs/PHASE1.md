# Phase 1 — architecture and design system

Priority Property Pros (PPP) is a **local home-services marketplace**. PPP is not the contractor. Roles planned for later phases: PPP, Customer, Independent Contractor, Independent Completion Verifier.

This document describes **Phase 1 only**: a static, installable frontend ready for GitHub Pages.

## What shipped

- React + TypeScript + Vite + Tailwind CSS homepage
- Original brand mark, wordmark, favicon, and PWA icons
- Design tokens and UI primitives (button, input, toast, bottom sheet, skeleton)
- App shell with iPhone-first bottom navigation and safe-area insets
- Placeholder routes for later product surfaces
- PWA: web manifest, service worker, offline fallback
- GitHub Actions CI (typecheck, lint, test, build) and Pages deploy

## What did not ship (later phases)

Phases 2–13 are **not implemented**: Supabase, auth, Stripe Connect, database, Edge Functions, live posting, messaging, payments, verification, or a demo role switcher.

`.env.example` lists public placeholders only. Phase 1 needs **no secrets**.

## Design tokens

Documented in `src/index.css` (`@theme`).

| Token | Value | Use |
| --- | --- | --- |
| Forest 800 | `#1A3C2E` | Primary brand, header, primary buttons |
| Forest 950 | `#0A1612` | Deep text on gold/cream contrast spots |
| Cream 50 | `#FBF8F1` | App background, PWA theme companion |
| Cream 100 | `#F3EBDA` | Cards, chips |
| Ink | `#1A1814` | Body text |
| Gold 500 | `#C9A227` | Accent rules, focus, Priority details |
| Gold 600 | `#A6851F` | Gold hover / labels |

Typography: **Fraunces** (display, editorial American) + **Outfit** (UI). Not Inter. Not a generic SaaS gradient.

Motion: 180–280ms ease for sheets and toasts. No decorative parallax.

## App shell

- Mobile: logo header + bottom tab bar (Home, Find, Post, Pros, Sign in)
- Desktop: full top nav from the spec
- Touch targets ≥ 44px
- `viewport-fit=cover` and `env(safe-area-inset-*)`
- No horizontal page scroll

## GitHub Pages base path

Vite `base` reads `BASE_PATH`:

- Local and custom domain at root: `BASE_PATH=/` (default)
- This repo as a project site: `BASE_PATH=/priority-property-pros/`

The app uses `import.meta.env.BASE_URL` for the router basename and public asset URLs.

## PWA

- Manifest generated by `vite-plugin-pwa`
- Icons in `public/icons/` (192, 512, maskable 512) plus `apple-touch-icon.png`
- Offline page: `public/offline.html`
- Service worker caches the static build and uses `index.html` as navigation fallback

Regenerate raster icons after editing the mark:

```bash
npm run icons
```
